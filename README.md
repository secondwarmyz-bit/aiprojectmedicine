# 🧬 AI Medical Research Bounty

Децентрализованная платформа прямого финансирования ученых и научных лабораторий, исследующих нерешенные медицинские вызовы и неизлечимые заболевания (онкология, нейродегенеративные патологии, редкие генетические мутации, суперинфекции).

Платформа исключает бюрократических посредников традиционных грантовых институтов: доноры и меценаты перечисляют криптовалюту **Solana (SOL)** напрямую на адреса исследовательских групп через кошелёк **Phantom**, а намерения и протоколы фиксируются в блокчейне через программу **SPL Memo**.

---

## 🚀 Основные возможности

* **Прямые крипто-пожертвования (Solana Devnet)**:
  * Перевод SOL непосредственно в кошелёк исследовательской лаборатории через `SystemProgram.transfer`.
  * Никаких удержаний и комиссий платформы — 100% средств поступают на закупку биореактивов, клеточных линий и аренду оборудования.
  * Прямые ссылки на подтверждённые транзакции в [Solana Explorer](https://explorer.solana.com/?cluster=devnet).

* **Он-чейн реестр (SPL Memo Program)**:
  * Фиксация выбора исследователя и намерений поддержки в неизменяемом распределённом реестре Solana с помощью программы `MemoSq4gqABAXKb96qnH8TysNcWxMyWCqXgDLGmfcHr`.
  * Текст кодируется через нативный `TextEncoder` без использования устаревших буферов.
  * История всех транзакций отображается в публичном реестре записей.

* **Интеграция с кошельком Phantom (`window.phantom.solana`)**:
  * Подключение через `window.phantom.solana` с автоматическим отслеживанием событий смены аккаунта и отключения.
  * Отображение первых и последних 4 символов адреса кошелька (`7xKX...gAsU`).
  * Получение реального баланса в сети **Solana Devnet** через библиотеку `@solana/web3.js`.
  * Встроенный инструмент запроса тестовых средств (**+1 SOL Devnet Airdrop**).

* **AI-ассистент для ученых (Google Gemini API)**:
  * Помощь исследователям в структурировании заявки на грант: автоматическое формулирование ключевого научного барьера, гипотезы и сметы расходов лаборатории.
  * Серверные маршруты Next.js API Routes (`/api/research/assist`) на базе официального SDK `@google/genai`.

* **Каталог исследований и прозрачная смета**:
  * Карточки актуальных исследовательских сборов с подробным описанием сути проблемы (почему классическая коммерческая фарма не финансирует фундаментальный тупик).
  * Детализированная смета лаборатории (проценты и суммы в SOL / USD).
  * Фильтрация по научным дисциплинам: *Онкология*, *Неврология & Нейродегенерация*, *Генетические патологии*, *Суперинфекции & Резистентность*, *Редкие заболевания*.

## 📦 Быстрый старт и локальный запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/ai-medical-research-bounty.git
cd ai-medical-research-bounty
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env.local` на основе примера:
```bash
cp .env.example .env.local
```

Заполните переменные:
```env
# API-ключ Gemini для работы AI-помощника формулирования гипотез
GEMINI_API_KEY="ваш_ключ_google_gemini"

# Базовый URL приложения
APP_URL="http://localhost:3000"
```

### 4. Запуск сервера разработки
```bash
npm run dev
```
Откройте браузер по адресу [http://localhost:3000](http://localhost:3000).

## 🔌 Настройка Phantom Wallet для работы с Solana Devnet

Для тестирования реальных транзакций в тестовой сети:

1. Установите расширение **Phantom** в браузер ([phantom.app](https://phantom.app/)).
2. Откройте Phantom $\rightarrow$ нажмите на значок **Настройки** (шестерёнка внизу справа).
3. Перейдите в **«Настройки разработчика»** (Developer Settings).
4. Включите **«Режим тестнета»** (Testnet Mode).
5. В разделе **«Изменить сеть»** выберите **Solana Devnet**.
6. В приложении нажмите **«Подключить кошелёк»** и запросите тестовый **1 SOL** через меню кошелька (или используйте faucet `solana airdrop 1`).
